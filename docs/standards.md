# 规范与参数说明（粗稿用）

本项目不是规范全文复刻，也不是合规证明。所有参数见
`src/cad_auto_draft/standards.py`，且都可以在输入 JSON 里覆盖。

## 覆盖的系统

- **给水**：洁具当量、设计秒流量 `qg = 0.2 α √Ng`、干管初选管径
- **排水**：按洁具选排水管径、按管径给最小坡度初值、排水立管与出户管
- **雨水**：屋面面积、降雨强度换算流量、雨水立管数量与间距初值
- **消火栓**：室内消火栓 DN65、软管 25 m、自检有效半径取 20 m（保守）
- **喷淋**：按危险级（轻 / 中 I / 中 II）取保守喷头间距网格
- **灭火器**：按 A 类、危险级取最大保护距离，出口先布点、走廊再补点

## 必须人工复核的项

1. 现行规范版本与地方条文、消防审查意见
2. 危险级、防火分区、建筑高度与用途是否与输入一致
3. 水压、水力计算、雨水重现期、喷淋作用面积与最不利点
4. 结构、梁、剪力墙、管井的真实冲突（本程序只避让输入的 obstacles）
5. 管材、阀门、报警阀、水泵接合器等系统设备（本版只出平面粗稿）
