# AutoCAD / 天正接入说明

## 本版的做法：DXF 粗稿

程序输出的是标准 DXF（R2010），AutoCAD 可以直接打开，天正
（T20 / T30，须与所装 AutoCAD 版本对应）也可以直接打开查看。

在 AutoCAD / 天正里：

1. 打开 `output/draft.dxf`，另存为 DWG
2. 检查中文文字字体，如显示异常，把标注文字样式字体改为 SimSun 等中文字体
3. 按院标准重命名图层、线型、颜色
4. 把普通直线、圆等粗稿元素，替换 / 转换为天正给排水、消防的
   专用管线、设备与标注对象，再做正式标注、统计与出图

## 为什么不直接生成天正专用对象

天正的给排水、消防对象是自定义实体，不同版本、不同 AutoCAD
平台的接口与对象定义并不完全相同。直接写天正对象而不经过
天正本身校验，很容易出现代理图形、统计失效、版本打不开。

所以本项目的定位是：**离线生成可复核的 DXF 粗稿**，正式图面
仍在天正里完成。这是目前最稳、也最容易落地的一步。

## 下一步：AutoCAD 插件路线

如需在 CAD 内一键生成，可按以下路线扩展（不在本版代码中）：

1. 用 C# / .NET 写 AutoCAD 插件，调用本项目的布局结果（JSON）
2. 在插件内用 AutoCAD API 画线、建块、写图层
3. 能调用天正命令的，用天正命令生成专用管线；不能调用的，
   先出普通图元，再由工程师在天正里转换
4. 插件必须按 AutoCAD 版本 + 天正版本分别编译测试，不能一个
   DLL 通吃所有版本

## 重要提醒

- 本程序需要 Windows + AutoCAD 才能做正式出图，Linux / NAS
  上只能跑粗稿生成与自检，不能替代 AutoCAD。
- 粗稿不得直接用于施工，须经注册工程师复核签字。
